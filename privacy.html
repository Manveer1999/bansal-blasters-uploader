Privacy Policy

Bansal Blasters Uploader · Last updated 20 October 2026

Bansal Blasters Uploader ("the tool") is a personal tool operated by Manveer Singh, V.P.O. Dehriwal, Punjab, India 144204, used only to manage his own YouTube channel.

YouTube API Services

The tool uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data is accessed

With the channel owner's OAuth consent, the tool accesses only the owner's own YouTube account in order to upload videos, set thumbnails, and read the status and statistics of the owner's own videos and channel. It does not access any other user's data.

How data is used and stored

The OAuth token is stored only on the owner's computer, with file permissions restricting it to that user. Video files and metadata stay on that computer until the owner uploads them. No data is sold, shared with third parties, or used for advertising. No cookies or analytics are used.

Revoking access

Access can be revoked at any time at Google security settings. Deleting the local token removes all stored credentials.
